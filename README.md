# まちの店手帖

行ったお店を記録して、Googleマップ上で見返せるWebアプリです。お店をタップすると、現在地からの徒歩ルートや電車・バスでの行き方が表示されます。

- 地図：Googleマップ（天神・博多・中洲へのジャンプボタンあり）
- 登録：店名で検索すると、位置・住所・エリア（天神、大名、博多駅前など）が自動で入ります
- 写真：入口・出口・外観・料理などを1軒8枚まで
- 共有：スマホの共有メニュー（LINE・Instagram・Xなど）から紹介できます
- 保存先：使っている端末の中です。メニューの「バックアップを保存」でファイルに書き出し、別の端末で「読み込む」と移せます

ビルド作業は不要で、このフォルダをそのまま公開すれば動きます。

---

## セットアップ（初回だけ、20分ほど）

### 1. Google Maps Platform の APIキーを作る

1. https://console.cloud.google.com/ にGoogleアカウントでログインします
2. 画面上部で新しいプロジェクトを作ります（名前の例：machi-techo）
3. 「お支払い」でクレジットカードを登録します（Google Maps Platform の利用に必須です）
4. 「APIとサービス」→「ライブラリ」で、次の3つを検索して **有効にする** を押します
   - **Maps JavaScript API**（地図の表示）
   - **Places API (New)**（店名検索）
   - **Routes API**（徒歩・電車ルート）
5. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」でキーを作ります（`AIza...` で始まる文字列）

### 2. APIキーに制限をかける（必ずやってください）

アプリの中のキーは、誰でも見られる状態になります。自分のサイト以外で使われないように、キーの編集画面で次のように設定します。

- **アプリケーションの制限**：「ウェブサイト」を選び、公開したURLを追加します
  - 例：`https://あなたのサイト名.netlify.app/*`
- **APIの制限**：「キーを制限」を選び、上の3つのAPIだけにチェックを入れます

あわせて「お支払い」→「予算とアラート」で、月額の予算アラート（例：1,000円）を設定しておくと安心です。料金は Google Maps Platform の料金ページで確認してください。APIごとに毎月の無料利用枠があるので、個人で使う程度なら通常は無料枠の中に収まります。

### 3. インターネットに公開する（Netlify Drop）

現在地の取得には `https://` のサイトが必要なので、無料のホスティングに置きます。

1. https://app.netlify.com/drop を開きます（無料アカウントを作ります）
2. この **machi-techo フォルダごと** ブラウザにドラッグ＆ドロップします
3. 表示された `https://〜.netlify.app` のURLを、手順2の「ウェブサイト」の制限に追加します
4. サイト名は Netlify の「Site configuration」→「Change site name」で変えられます

アプリを更新したときは、Netlify のサイト画面の「Deploys」に、フォルダをもう一度ドラッグします。

### 4. APIキーを入れる

どちらかの方法で入れます。

- **かんたん**：公開したURLを開くと入力画面が出るので、キーを貼り付けます（その端末にだけ保存されます）
- **全端末で共通にする**：`config.js` の `GOOGLE_MAPS_API_KEY: ""` の `""` の中にキーを書いてから公開します

### 5. スマホのホーム画面に追加する

- iPhone：Safariで開く →「共有」→「ホーム画面に追加」
- Android：Chromeで開く →「︙」→「ホーム画面に追加」

初めて「現在地」や「歩いて行く」を押すと、位置情報の許可を求められるので「許可」を選びます。

## 使い方

| やりたいこと | 操作 |
|---|---|
| お店を記録 | 「＋ 記録する」→ 店名で検索 → 候補を選ぶ → 保存 |
| お店にいるときに記録 | 記録画面の「今いる場所で登録する」 |
| 行き方を調べる | 地図のお店をタップ →「歩いて行く」または「電車・バスで行く」 |
| ナビを使う | ルート画面の「Googleマップアプリでナビを開始」 |
| 友達に紹介 | お店の詳細 →「友達に共有」 |
| 別の端末に移す | メニュー（⋯）→「バックアップを保存」→ 移したい端末で「読み込む」 |

## うまくいかないとき

- **地図が出ない／「APIキーが使えませんでした」と出る**：手順1の3つのAPIが有効になっているか、キーの「ウェブサイト」制限に今のURLが入っているかを確認してください
- **店名検索ができない**：「Places API (New)」が有効か確認してください（「Places API」の旧版とは別物です）
- **ルートが出ない**：「Routes API」が有効で、キーの「APIの制限」にも含まれているか確認してください
- **現在地が取れない**：`https://` で開いているか、ブラウザの位置情報が許可されているかを確認してください
- **地図のデザイン**：`config.js` の `MAP_ID` はテスト用の `DEMO_MAP_ID` です。Google Cloud の「マップ管理」で自分のマップIDを作って差し替えると、地図のスタイルを変えられます

```
machi-techo/
├─ index.html            画面の骨組み
├─ style.css             見た目
├─ app.js                動き（地図・検索・ルート・保存）
├─ config.js             APIキーの設定
├─ manifest.webmanifest  ホーム画面に追加したときの設定
└─ icon.svg              アイコン
```
